How GRR and NRR are calculated

GRR = (S − C − Dn) ÷ S × 100   ·   NRR = (S − C − Dn + U) ÷ S × 100
SStarting MRR - total MRR of the cohort at the start month
CChurn - start MRR of cohort customers whose MRR is now $0
DnDowngrades - MRR lost by cohort customers who now pay less
UUpgrades - extra MRR from cohort customers who now pay more
K, EKept = S − C − Dn; Ending = K + U
  1. Window. TTM: start month = 12 months before the period end. Period window: the prior month (monthly) or the prior quarter end (quarterly).
  2. Cohort. Every customer with MRR > 0 in the start month. Customers who start later are new business and are excluded.
  3. Compare. For each cohort customer: a = MRR in the start month, b = MRR in the end month (same MRR as the MRR page: monthly lines, annual ÷ 12, quarterly ÷ 3, retainers).
  4. Constant currency. CAD customers are converted at the start month's rate at both ends, so FX moves never show as churn or upgrades.
  5. Classify each customer once. b = 0 → churn (C += a) · 0 < b < a → downgrade (Dn += a − b) · b > a → upgrade (U += b − a) · b = a → flat.
  6. Ratios. GRR = K ÷ S, NRR = E ÷ S. GRR excludes upgrades so it can never exceed 100%; NRR includes them. Benchmarks: GRR 90% (TTM), NRR 100% (TTM).

Churn is revenue churn from invoices: a customer is churned when no recurring invoice line covers the end month. "Subscription only" runs the same calculation without retainer MRR.

How marketing ROI is calculated (spec CM-07)

  • ROI = new-business pipeline created ÷ marketing spend for the same period.
  • Pipeline = {{ 'ARR' if cfg.value_field == 'arr' else 'amount' }} of {{ cfg.provider }} deals of type {{ (cfg.nb_types or [])|join(', ') }} created in the period (created date, not close date), whatever their stage, with a marketing lead source: {{ (cfg.mk_sources or [])|join(', ') }}.
  • Blended = ÷ all marketing P&L accounts; Programs = ÷ program spend accounts (Settings).
  • Channels: {% for c in cfg.channels %}{{ c.name }} = {{ c.sources|join(' + ') }} deals ÷ its P&L accounts{{ '; ' if not loop.last }}{% endfor %}. All spend comes from the P&L snapshots in MongoDB.
  • Quarterly view shows complete quarters only; the last month is the latest P&L snapshot ({{ cfg.pl_last }}).
